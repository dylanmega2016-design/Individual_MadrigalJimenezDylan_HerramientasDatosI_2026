# Configuración del proyecto

El proyecto no requiere archivos de configuración externos.

Los parámetros del procesamiento EEG, las bandas espectrales,
la selección de electrodos y los criterios del análisis
estadístico se encuentran definidos y documentados dentro
de los respectivos scripts de la carpeta `cod/`.

Esta carpeta se conserva como parte de la estructura
organizativa del proyecto.
