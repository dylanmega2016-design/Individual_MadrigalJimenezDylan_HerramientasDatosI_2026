# Proyecto individual - GAMEEMO

Curso: Herramientas de Ciencia de Datos I
Universidad de Costa Rica

## Descripción

Análisis de las respuestas emocionales y señales EEG de 28
participantes durante cuatro videojuegos, con especial
atención a las experiencias de terror y diversión.

## Herramientas

- R y RStudio
- tidyverse
- ggplot2
- Git y GitHub
